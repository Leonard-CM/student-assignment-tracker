# Contributing to Student Assignment Tracker System

Thank you for contributing to the Student Assignment Tracker System project.

This project was developed as part of a Software Engineering portfolio and follows professional GitHub collaboration practices.

---

# Project Overview

The Student Assignment Tracker System helps students manage:

- Subjects
- Assignments
- Notifications
- Task progress
- Dashboard tracking
- Academic workflows

The project is built using:

- Java 17
- Spring Boot
- Maven
- JUnit 5
- GitHub Actions CI/CD
