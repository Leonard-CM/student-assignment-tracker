# Assignment 15 - Cross-Project Contributions

## Overview

This document records all contribution activities completed for Assignment 15.

The objective of this assignment was to participate in collaborative software development through contributions to peer repositories.

---

## Contribution Workflow

For each contribution the following process was followed:

1. Review repository documentation
2. Review CONTRIBUTING.md
3. Identify suitable issue
4. Comment on issue
5. Fork repository
6. Create feature branch
7. Implement changes
8. Run tests
9. Submit pull request
10. Address review feedback
11. Merge contribution
