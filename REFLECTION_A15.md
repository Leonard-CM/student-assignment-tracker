# Reflection – Assignment 15

Assignment 15 provided practical experience in collaborative software development by contributing to peer repositories through GitHub pull requests.

Unlike previous assignments which focused on developing and managing my own repository, this assignment required engagement with external codebases and collaboration with other developers.

One of the most valuable lessons learned was the importance of understanding project guidelines before making changes. Reviewing CONTRIBUTING.md files, coding standards, and issue discussions helped ensure contributions aligned with project expectations.

The assignment also reinforced the importance of communication. Commenting on issues before starting work reduced duplication of effort and improved collaboration with repository maintainers.

Working across different repositories exposed me to different coding styles, repository structures, and development workflows. This improved adaptability and strengthened understanding of real-world software engineering practices.

Another key lesson involved pull request management. Creating focused pull requests with clear descriptions, testing evidence, and issue references increased the likelihood of successful reviews and merges.

The experience demonstrated how modern software development relies heavily on collaboration, communication, code reviews, and continuous integration processes.

Overall Assignment 15 strengthened practical skills in GitHub workflows, collaborative development, open-source contribution, and professional software engineering practices.
